# 构建 Windows 便携包

便携包支持 Windows 10 1903 及以上 x64 或 Windows 11，需要 Microsoft Edge WebView2 Runtime。完整解压到可写目录，保留程序旁的配置、运行帧和 DLL，再运行 exe。

## 从源码构建

在仓库根目录安装 Node 依赖，然后运行打包脚本。构建环境需要 Rust MSVC 工具链及 Visual Studio C++ Build Tools。

```powershell
npm install
.\tools\package_portable.ps1
```

脚本构建 Tauri release 程序，按白名单收集配置、曲库、动画引用的运行帧、叠加素材和音源署名，在 `dist/` 生成便携目录、ZIP 和 SHA256 校验文件。包名包含版本、构建时间与 Git 短提交号。工作区包含未提交修改时，构建号会带有 `dirty` 标识。

## 运行库和本地数据

脚本从 Visual Studio 的 `Redist/x64/Microsoft.VC143.CRT` 获取正式 x64 运行库，也可用 `-VcRuntimeDirectory` 指定该目录。必需 DLL 为 `msvcp140.dll`、`msvcp140_1.dll`、`vcruntime140.dll` 和 `vcruntime140_1.dll`。WebView2 和 DirectML 等系统组件由运行环境提供。

便携版在 exe 目录读取运行素材并保存偏好与日志。包内仅含运行所需的公共资源，个人设置、凭据、聊天库、存档、日志和模型缓存均在白名单之外。游戏和日常互动可离线使用，交流功能需配置 API。

更新前请退出旧版并备份需要保留的数据。交流数据库升级说明见[迁移与备份](记忆底层重整-实现与验证-20261103.md#迁移与备份)。
