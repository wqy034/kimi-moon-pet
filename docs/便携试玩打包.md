# Windows便携试玩包

2026-10-28补充：本地记忆引入的ONNX Runtime静态库仍导入MSVC C++运行库，便携包必须携带正式x64 CRT DLL。脚本通过vswhere/VCToolsRedistDir查找Visual Studio的Redist/x64/Microsoft.VC143.CRT，也可用-VcRuntimeDirectory指定该目录；不从System32或debug_nonredist取文件。必需四项为msvcp140.dll、msvcp140_1.dll、vcruntime140.dll、vcruntime140_1.dll，其余CRT扩展按明确白名单复制。附运行库说明、ZIP同名SHA256校验文件。运行要求Windows 10 1903及以上x64或Windows 11、WebView2；DirectML等系统组件不复制。检查产物PE依赖和ZIP白名单，不把本机能运行等同于干净电脑实测。

运行 `tools/package_portable.ps1`：先执行Tauri release构建（不生成安装器），再按动画配置白名单收集exe、动画配置引用的运行帧、动画/边界/养成配置、曲库及两张程序叠加素材，输出到被Git忽略的dist目录并生成ZIP。运行帧数量以当前动画配置为准，新增动作会自动进入白名单；音源嵌入前端资源并保留随包署名。

开发版继续读取仓库目录；release版读取当前exe所在目录。asset协议作用域在启动时仅开放该目录下的config/帧文件/道具，消除开发机固定盘符依赖。正式版隐藏控制台。

不复制原config目录、用户设置、密钥、凭证、state.json、备份帧、美术源图或日志。朋友首次保存偏好才生成自己的设置文件，运行日志也保存在exe旁边；因此便携文件夹需可写。

解压整个包再运行exe，不能单独移动exe。无需Node/Rust/Kimi CLI；需要Windows x64及WebView2运行时。不连CLI也能使用本地互动和日常生活，额度查询需要朋友本机自己的Kimi登录。

产物为未签名内部试玩包，不是安装器。说明文件随包提供。只做正式构建、产物文件检查及进程/日志检查，鼠标交互仍由用户和朋友手动体验。


版本号同步更新package.json、package-lock.json、src-tauri/Cargo.toml、Cargo.lock中的pet-engine以及tauri.conf.json。便携文件夹及ZIP名称包含语义版本、日期和Git短提交号，说明中同时写出版本与构建号。

包名包含构建时间。工作区包含未提交修改时，构建号带有 dirty 标识。试玩说明从源码读取聊天数据库版本。
