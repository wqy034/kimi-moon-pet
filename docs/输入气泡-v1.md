# 输入气泡与对白

双击桌宠打开或隐藏输入条。右键菜单和托盘菜单的「跟她说话」也能打开输入条。

- Enter 发送，Shift+Enter 换行。确认中文输入法候选时不会发送。
- 点击输入条左侧的圆球可收起或恢复。拖动圆球可移动输入条。
- 收成圆球时保留本次编辑的文字。按 Esc 或双击隐藏输入条会清空未发文字，重启后也不会恢复草稿。
- 发送失败会保留输入。等待回复时可以继续编辑，当前请求结束后才能发送下一条。

## 等待与查看回复

生成时显示等待状态。回复接收完成并通过校验后显示在对白气泡中，较长的回复可以展开或滚动阅读。隐藏输入条或收起气泡后，请求仍会继续。要结束生成，请点击对白窗口的「停止」或交流设置的「停止回复」。

在右键或托盘菜单中打开「交流设置」可管理 API 连接、查看原始交流和长期记忆。详见[配置多组 API 连接](多服务商API-v2.md)与[暗月的人设与交流校验](暗月人设与交流防护-v1.md)。

## 窗口与交互实现

输入条为 320×42 逻辑像素，圆球为 42×42。打开时优先放在桌宠主窗口上方，空间不足时放到旁边或下方。手动移动后，输入条按屏幕位置独立摆放。收起或恢复时尽量保持圆球位置。显式打开或恢复时请求输入焦点，失焦时保留当前输入。

Rust 端串行处理窗口显隐、尺寸和焦点，通过 Tauri 的窗口接口保持原生窗口与框架状态一致。窗口命令以 Rust 保存的当前状态为准。发送请求与对白操作分别校验会话代次或请求 ID，防止迟到事件覆盖新的输入和回复。

桌宠使用系统双击时间和点击范围区分轻触与双击。等待双击判定结束后才播放单击反馈。双击打开输入条时只触发输入操作。长按或拖动进入拎起交互。

输入、生成与回复展示期间，行为调度器暂停部分自主活动。临时反馈结束后，尚有效的聊天回复可恢复显示。闲置圆球不会持续占用交流状态。

## 验证步骤

- 核对双击、Esc、圆球拖动和收起恢复，覆盖不同缩放比例和屏幕边缘。
- 用多行文本和中文输入法验证发送与换行。收成圆球再展开时应保留编辑内容，隐藏再打开时应清空。
- 用测试连接检查停止回复、请求失败和切换连接。确认停止后不会出现旧请求的迟到回复。
