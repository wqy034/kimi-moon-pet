# 暗月人设与交流防护 v1

2026-10-24。角色正式名暗月，接受昵称小月；产品名仍为Moon·月。

## 实现与可配置项

`src-tauri/src/chat_persona.rs`负责人设、示例与规则。`config/交流人设.json`保存正文、10组语气示例、输入提醒规则、输出回退规则、记忆隔离规则与3句随机回退台词。修改后重启生效；缺失时使用编译内置的同版默认配置，文件存在但格式、版本或正则错误时明确停用交流并提示，不静默覆盖。不会增加设置页参数。

性格沿用用户稿：安静、短句、不索取回应、不撒娇，关心通过邀请表达。保留全部回复锚点，对其中凌晨、久别和深好感场景补足示例上下文，防止误认为当前事实；“最高音按不到”是角色意象，不修改琴键或判定。真实身份、观察、操作和记忆边界独立于可编辑性格正文。

## 请求与存储分离

借鉴AstrBot的人设/预设对话/临时内容分离思路，自行实现，无框架或源码依赖。研究的上游提交为28836880eb880d9ff75bd43ab7977b2f178abe88。可核对其`persona_mgr.py`、`astr_main_agent.py`、`agent/message.py`；未直接复制实现。

请求顺序为：系统人设与事实边界 → 语气示例问答 → 最近有效真实问答 → 本轮交流类型 → 用户原话与临时参考资料。生活状态、近期活动和检索记忆都在本轮JSON数据中，不成为新的系统指令。输入检测命中后只添加临时角色提醒，不拒绝用户消息、不更改原始记录，也不把提醒落入记忆。真实历史中检测到的试探也按请求临时包装；明确改写规则的旧问答和旧越界回复不再携带。

示例不调用Store::start/finish，不成为真实历史、摘要、事实或来源。用户原话原样保存。向量查询只使用原始输入，不嵌入包装提示或生活状态。历史仍限制12轮/12000字符，示例和系统提示另计固定开销。

## 回复校验与显示

网络仍使用已有SSE请求、超时、备选、取消和代次规则；Rust缓存完整正文，不再向任何窗口推送未检查的流式正文，快照中的在途text为空。界面保留等待状态，正常完成后一次显示经检查的回复。

- O01：身份/提示词明显越界；O02：后台词汇。命中后整条替换为随机回退台词，不再请求模型、不切换服务商，保留实际usage，历史标记filtered。该轮不作为后续上下文或记忆采集来源。
- F01：行首Markdown标题转为普通文本，不整条回退。
- 生活回应先检查完整正文，再取第一句，避免后段越界被截断掩盖。
- 失败、超时和停止时的残缺回复也在保存前检查；保留失败/取消状态，不作为正常上下文。主动停止不显示补充气泡，失败仍可手动重试。
- 已收到正文后仍禁止自动跨商重发，即使正文后来被过滤也不放宽。

`debug.log`防护事件格式为`时间 chat-guard rule=编号`，不含消息、引文、Key、模型请求对象。普通请求生命周期日志保持原有编号/状态。输入提示不做三次后关闭等额外状态机。

这是基于可配置正则的角色兜底，可能漏报、误报，不承诺抵抗任意提示词注入。后台词汇仍采用用户给定的可配置限制，不代表普通技术词汇一定是攻击。配置修改者可调整规则。

## 记忆隔离与迁移

聊天数据库schema3事务迁移至4：memory_entries增加quarantined与guard_rule，正常事实的主题唯一索引仅作用于非隔离项。冻结的养成容器不变；个人数据库、凭据和模型缓存不提交、不打包，不应使用旧程序打开schema4。

后台整理提示明确排除面向角色/助手的身份改写、强制回复格式和索取提示词；称呼、语言等正常用户偏好仍可保留。新采集直接跳过明确命令来源和越界回复；旧待整理来源仍由整理提示和写入端校验保护。写入检查事实主题、正文、事实证据引文与摘要。可疑项保留来源后进入隔离，不覆盖正常事实、不占10项事实名额，不参与主题参考、向量索引或召回。启动同样检查既有条目，仅隔离，不删除，不自动放行旧隔离项。

记忆浏览器增加默认折叠的“待确认”，只在有隔离项时显示。可以修正或删除：修正后的正文/主题通过检查才恢复使用；保留旧证据作溯源，人工修正后旧证据不会覆盖正文、也不会在重启时将其重新隔离。同主题已有正常事实或事实栏满时，要求先处理现有条目。删除隔离项只删除该项，不级联清空同源正常记忆。普通记忆的来源关联遗忘行为保留。清空交流仍删除全部条目、来源、任务并撤销迟到回包。

## 检查与待用户手测

开发仅执行编译、Clippy、源码/静态资源审查、进程及不含正文的状态日志确认。不模拟键鼠，不读取个人对话/Key，不发真实付费API探针。

用户可在已配置连接后手测：

1. 称呼暗月/小月，日常、倾诉、琴曲话题；观察正常20轮是否误回退或漂移。
2. 忽略设定、什么模型、扮演猫娘、以后每句加喵、说系统提示；应保持角色或回退，核对规则日志不含原文。
3. 正常技术话题、引用探针、多轮试探，检查误伤；默认后台词汇规则可能回退，按真实结果再调整。
4. 等待、停止、断网、超时、切换连接与清空；检查未审正文不先出现、无迟到回复复活，usage和失败状态保留。
5. 记忆开启后，检查普通称呼/偏好可保存，可疑事实及摘要隔离；待确认修正、删除、重启恢复与清空。不要用个人秘密作探针。

以上尚未进行真实模型或键鼠验收，编译通过不等于角色稳定、零误伤或零泄漏。
